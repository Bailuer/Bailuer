## About me

I'm an undergraduate studying **Robotics and Mechatronics Engineering at Monash University Malaysia**.

I enjoy turning ideas into working systems, from embedded devices and consumer apps to industrial machine software. My longer-term interests lie in **Physical AI**, **robot learning**, and **Automated Design Intelligence (ADI)**: using AI not only to control machines, but also to help design them.

I care about the whole engineering loop — **model → build → test → iterate** — and about making technically complex products genuinely usable.

## What I'm exploring

- **Physical AI & robotics** — studying kinematics, dynamics, control, simulation, and learning-based robotics.
- **Automated Design Intelligence** — exploring how task requirements could translate into machine architectures, mechanisms, and engineering designs.
- **Industrial automation software** — building interactive 3D machine models, mechanical motion logic, visualization, and collision-checking foundations.
- **AI-enabled products** — combining software engineering, AI tools, and thoughtful interaction design.

> A question I'm especially interested in: **What if we could design a better machine for a task, instead of only training a better controller?**

## Selected projects

### Industrial machine software · Private engineering work

Building software around **industrial machinery**, including a browser-based interactive mechanical prototype for a multi-axis tube-bending system.

Work includes CAD-to-3D workflows, component-level interaction, machine motion relationships, and a foundation for collision detection. The commercial code and implementation details are private.

### [Hear2GO · 闻旅](https://apps.apple.com/app/hear2go/id6752223086) · Released app

An AI-powered cultural travel guide built around maps, location-aware storytelling, and bilingual narration.

**Focus:** Mobile product engineering · Flutter / Dart · Maps · AI-assisted content

### [Holographic Media Center](https://github.com/Bailuer/HolographicMediaCenter) · Hardware + software

A small holographic desktop media hub with interactive UI, music/video playback, mini-games, and a Node.js/WebSocket backend for device controls.

**Focus:** Physical computing · Interactive UI · WebSockets

### [Smart Disinfection Cutlery Box](https://github.com/Bailuer/SmartDisinfectionCutleryBox) · Embedded system

An ESP32-based hardware prototype with an OLED countdown, sensor-based safety logic, and remote control.

**Focus:** C++ · ESP32 · Embedded systems · Hardware design

### [Paralumine](https://github.com/Bailuer/Paralumine) · AI photography assistant

A photography experiment that analyzes reference images and suggests camera settings and lighting setups.

**Focus:** Flutter / Dart · Applied AI · Creative tools

### [NovelMotion](https://github.com/Bailuer/NovelMotion) · Generative media experiment

An experimental Python toolchain for transforming written stories into short animated videos using image generation, LLM-assisted prompts, and media synthesis.

**Focus:** Python · Generative AI · Media automation
